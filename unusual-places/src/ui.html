Honest details.

Offbeat is a curated directory of unusual places in Germany. Start with a city, follow your curiosity, and save a few discoveries for another day.

  • Your shortlist and day trip are saved for this browser visitor, not a shared account.
  • Distances and travel gaps are straight-line estimates. Check real routes, opening hours, access, and tickets before you go.
  • Photographs link to their source and attribution in each place’s details. Sources can change.
  • The in-app guide is a rule-based demo. It interprets locations, distances, and interests — it is not an LLM.

Under the hood

One directory, two ways to explore: this web app uses a JSON API; embedded in ChatGPT, the same search can run through an MCP tool. The host receives selected places only when you choose to share them.
